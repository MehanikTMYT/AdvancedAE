# Реакционная камера

<BlockImage id="advanced_ae:reaction_chamber" scale="4"></BlockImage>

Реакционная камера ускоряет химические реакции с помощью жидкости-катализатора и
большого количества энергии. Естественные реакции можно принудительно проводить внутри
камеры; благодаря контролируемым условиям результат чаще всего получается эффективнее.

## Питание камеры

При ускорении реакционная камера может потреблять очень много энергии. Карты ускорения повышают
скорость расходования общей стоимости энергии, увеличивая потребление за тик. При питании напрямую
от МЭ-системы камера пытается получить энергию на один тик обработки. Если это
не удаётся, питание системы может начать включаться и выключаться. Для устранения этого
эффекта в системе AE нужны энергетические буферы — <ItemLink id="ae2:dense_energy_cell" />. Камера также может
получать энергию напрямую из энергетических ячеек Applied Flux в накопителях, заряжаясь и
выполняя рецепты без расходования энергетических буферов МЭ. Если увеличить выработку энергии пока
нельзя, можно уменьшить число карт ускорения. Для правильного питания есть несколько вариантов.
* Примечание: поставщики шаблонов и интерфейсы в виде частей кабеля не обеспечивают соединение с сетью. Для
питания камеры через них также потребуется подключить к ней флюисовый кабель напрямую.

### Поставщик шаблонов в виде полного блока

Поставщик шаблонов в виде полного блока соединяет реакционную камеру напрямую с сетью
AE2, позволяя получать энергию по необходимости без использования внутреннего буфера камеры. Если
общий запас энергии сети меньше потребления за тик, обработка замедляется, а на
экране появляется предупреждение. Для этого способа рекомендуется подключить к сети несколько <ItemLink id="ae2:dense_energy_cell" />.

### Внешнее питание

Другой способ питания реакционной камеры — внешний источник энергии. Любой
источник, способный передавать энергию, может заполнить буферы и запустить обработку.
Если энергия поступает слишком медленно, на экране камеры появляется предупреждение.

### Индукционные карты (требуется дополнительный мод Applied Flux)

Индукционные карты можно установить в поставщики шаблонов в виде частей кабеля или направленные
поставщики, чтобы экспортировать энергию из энергетических ячеек. При правильной настройке они заполняют энергохранилище
реакционной камеры и позволяют ей работать. Однако индукционные карты, как и некоторые другие
компоненты AE2, разгоняются постепенно. Поэтому вначале изготовление не достигнет максимальной скорости из-за недостаточного
запаса энергии, но по мере работы индукционная карта должна выйти на достаточную мощность.
