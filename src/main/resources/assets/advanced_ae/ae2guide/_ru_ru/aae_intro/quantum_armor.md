Каково это — носить свою МЭ-систему на себе? Теперь это можно узнать. Комплект
квантовой брони — высокотехнологичное незаметное снаряжение, которое подключается к системе AE2 и обеспечивает
удобный доступ ко всему на ходу! По умолчанию это питаемый энергией костюм с защитой
на уровне незеритового снаряжения. Он использует запас энергии для создания щита, поглощающего значительную
часть урона. Ботинки также предотвращают урон от падения, а нагрудник может устранять штраф к
скорости добычи в полёте. Но настоящие возможности костюма раскрываются только после установки улучшений!

<br/>

## Привязка брони

Каждую часть брони можно отдельно привязать к системе, поместив её в
соответствующий слот <ItemLink id="ae2:wireless_access_point" />. Это открывает разные возможности в зависимости от части
снаряжения и установленных карт улучшений. Подробнее о них ниже. Для работы
дополнительных функций также необходимо находиться в радиусе действия привязанной точки доступа.

<br/>

## Установка улучшений

Для установки улучшений нужно надеть снаряжение и открыть
меню настройки квантовой брони горячей клавишей (по умолчанию N).

![Настройка квантовой брони](../pic/quantum_armor_config.png)

На этом экране можно добавлять и удалять улучшения, включать и
выключать их, а также менять предусмотренные для них настройки.

<br/>

## Базовая карта Квантового обновления

<ItemImage id="advanced_ae:quantum_upgrade_base" scale="2"></ItemImage>

Сама по себе <ItemLink id="advanced_ae:quantum_upgrade_base" /> не даёт особых возможностей,
но используется как ингредиент при изготовлении всех карт улучшений.

<br/>

## Карта автоматического питания

<ItemImage id="advanced_ae:auto_feeding_card" scale="2"></ItemImage>

<ItemLink id="advanced_ae:auto_feeding_card" /> позволяет выбрать предметы для питания игрока. Достаточно перетащить нужные предметы
в слоты фильтра: если снаряжение привязано к сети AE2, оно
будет искать их в системе и кормить игрока при появлении голода.

<br/>

## Карта автозапаса

<ItemImage id="advanced_ae:auto_stock_card" scale="2"></ItemImage>

Для <ItemLink id="advanced_ae:auto_stock_card" /> также нужны привязка части снаряжения к системе AE2 и нахождение
в радиусе точки доступа. Карта позволяет задать несколько стопок, количество которых постоянно
поддерживается в инвентаре игрока. Количество в настройке слота не ограничено одной стопкой,
поэтому при желании можно постоянно заполнять одним ресурсом несколько слотов инвентаря.

<br/>

## Карты полёта

<Row gap="10">
<ItemImage id="advanced_ae:flight_card" scale="2"></ItemImage>
<ItemImage id="advanced_ae:flight_drift_card" scale="2"></ItemImage>
</Row>

### Карта полёта

<ItemLink id="advanced_ae:flight_card" /> открывает полёт как в творческом режиме. Скорость полёта настраивается ползунком в
интерфейсе. Улучшения скорости ходьбы и бега также увеличивают её, причём прибавки складываются.

### Карта улучшенного полёта

<ItemLink id="advanced_ae:flight_drift_card" /> работает только вместе с картой полёта и добавляет
ползунок настройки инерции в творческом полёте. Чем меньше
значение, тем быстрее остановка; при значении 0 она мгновенная.

<br/>

## Карта зарядки

<ItemImage id="advanced_ae:recharging_card" scale="2"></ItemImage>

<ItemLink id="advanced_ae:recharging_card" /> обеспечивает беспроводную зарядку надетой части брони. Нужны привязка
к сети и нахождение в радиусе точки доступа. При установке
в нагрудник карта дополнительно заряжает предметы в слотах инвентаря.

<br/>

## Карта переносного верстака

<ItemImage id="advanced_ae:portable_workbench_card" scale="2"></ItemImage>

<ItemLink id="advanced_ae:portable_workbench_card" /> добавляет в квантовый костюм портативный верстак ячеек. Он открывается назначенной
горячей клавишей и работает так же, как верстак в виде блока.

<br/>

## Карта запроса изготовления

<ItemImage id="advanced_ae:pick_craft_card" scale="2"></ItemImage>

<ItemLink id="advanced_ae:pick_craft_card" /> добавляет броне новую горячую клавишу. При нажатии она пытается
заказать изготовление блока, на который смотрит игрок. Для этого нужны
привязка к сети и подходящий шаблон. Во всплывающем окне задаётся
количество, после чего запрос обрабатывается как обычное задание автокрафта.

<br/>
