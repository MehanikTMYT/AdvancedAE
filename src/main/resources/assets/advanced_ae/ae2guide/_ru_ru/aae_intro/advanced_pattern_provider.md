МЭ Продвинутый поставщик шаблонов — новая разновидность <ItemLink id="ae2:pattern_provider" />. Он улучшает обычный поставщик
или расширенный поставщик шаблонов из Extended AE, позволяя задавать сторону подачи
для каждого отдельного предмета в шаблоне. Это позволяет автоматизировать машины, требующие подачи
разных ингредиентов с определённых сторон, с помощью одного блока без труб!

*Да, Mekanism, речь о тебе.*

Для использования этой функции нужен <ItemLink id="advanced_ae:adv_processing_pattern" />.
Чтобы получить его, следует вставить закодированный
шаблон в <ItemLink id="advanced_ae:adv_pattern_encoder" /> и забрать усовершенствованную версию.

Также есть расширенная версия, вмещающая до 36 шаблонов в одном поставщике.
