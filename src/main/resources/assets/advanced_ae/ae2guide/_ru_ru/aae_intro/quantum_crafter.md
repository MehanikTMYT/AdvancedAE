# Квантовый крафтер

<BlockImage id="advanced_ae:quantum_crafter" p:working="true" scale="4"></BlockImage>

Квантовый крафтер — мощное настраиваемое устройство автоматического изготовления. Доступ ко всему содержимому
системы AE упрощает непрерывное производство. Крафтер очень быстро выполняет задания, не позволяя
израсходовать важные ресурсы до конца. Он также поддерживает изготовление с заменой ингредиентов
жидкостями и рекурсивные рецепты, в которых один из ингредиентов входит в результат.

## Использование крафтера

Для работы квантовый крафтер нужно разместить в сети и подключить
кабелем. Требуется один канал. Рецепты для непрерывного изготовления следует записать
в шаблоны изготовления и вставить их в соответствующие слоты крафтера.

![Интерфейс квантового крафтера](../pic/quantum_crafter_ui.png)

После установки для каждого шаблона доступны две кнопки настройки. Квадратная кнопка внизу включает
и выключает шаблон. Выключенные шаблоны никогда не выполняются, а включённые подчиняются заданным условиям.
Чтобы настроить условия, нужно нажать кнопку с шестерёнкой и открыть интерфейс настройки шаблона.

![Настройка шаблона](../pic/pattern_configuration_ui.png)

В интерфейсе настройки шаблона перечислены все ингредиенты и основной результат.
Числовые поля задают минимальный запас каждого ингредиента в МЭ-системе и максимальное
количество готового продукта, чтобы не изготавливать лишние дорогие предметы. После 
ввода нужного числа (также поддерживаются математические выражения) нужно нажать Enter для
применения. Индикатор справа показывает, применено ли значение. Если ограничение результата
установить в 0, оно снимается и изготовление продолжается до исчерпания ингредиентов.

## Вывод результатов

Вывод результатов квантового крафтера гибко настраивается. По умолчанию предметы
отправляются из выходных слотов прямо в МЭ-систему. Нажатием ЛКМ
на кнопку ячейки в левой панели можно переключить вывод
в соседние инвентари. При включении этого режима появляется дополнительная
кнопка выбора сторон для автоматического экспорта. Вместе эти настройки позволяют
гибко управлять крафтером и находить разные способы его применения.

## Улучшения

Для полного раскрытия возможностей квантового крафтера нужны карты улучшений. Он поддерживает
<ItemLink id="ae2:speed_card" /> и <ItemLink id="ae2:redstone_card" />. Первые значительно ускоряют изготовление — до 64 операций
по каждому шаблону за тик, а вторые обеспечивают управление сигналом редстоуна.
