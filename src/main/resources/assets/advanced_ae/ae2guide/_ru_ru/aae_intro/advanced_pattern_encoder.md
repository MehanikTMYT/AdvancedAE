# Усовершенствованный кодировщик шаблонов

Чтобы указать МЭ Продвинутому поставщику шаблонов, куда отправлять предметы, требуется специальное устройство
для кодирования этой информации. Его интерфейс открывается нажатием ПКМ с устройством в руке.

<ItemImage id="advanced_ae:adv_pattern_encoder" scale="4"></ItemImage>

Закодированные шаблоны обработки вставляются в левый слот. Шаблон
расшифровывается, и все исходные ингредиенты отображаются в списке.

![Шаблон в кодировщике 1](../pic/ape_pattern.png)

В каждой строке есть кнопки всех сторон блока, на которые
можно отправить ингредиент. Выбор кнопки «A» означает отправку на сторону,
непосредственно соединённую с поставщиком шаблонов; выбор конкретной стороны принудительно направляет
предметы туда. Усовершенствованные шаблоны правильно расшифровывает только <ItemLink id="advanced_ae:adv_pattern_provider" />; в других
поставщиках они работают как обычные шаблоны. Кроме того, если хотя бы
один предмет нельзя вставить с указанной стороны, направленная вставка не
выполняется ни для одного предмета и применяется обычное поведение поставщика шаблонов.
