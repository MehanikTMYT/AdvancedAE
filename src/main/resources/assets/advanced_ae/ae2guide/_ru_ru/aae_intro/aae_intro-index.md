# Advanced AE!

Advanced AE делает работу с МЭ-системой удобнее и расширяет возможности систем поздней игры.
Мод позволяет улучшать поставщики шаблонов, чтобы отправлять предметы на заданные стороны целевых машин,
а также создавать мультиблочные компьютеры, выполняющие неограниченное число заданий изготовления с общими
сопроцессорами, пока хватает памяти изготовления. Кроме того, мод добавляет множество других полезных функций!
